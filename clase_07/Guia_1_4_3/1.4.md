## Propósito de la guía

Desarrollar la capacidad de organizar y manipular grupos de datos en Java mediante colecciones, comprendiendo cuándo conviene usar estructuras como ArrayList, HashSet o HashMap. Además, la guía busca fortalecer el control de errores mediante el uso de excepciones, permitiendo que los programas respondan de manera segura ante situaciones inesperadas como índices inválidos, datos nulos o conversiones incorrectas.

La guía presenta un caso base relacionado con la gestión de estudiantes inscritos en un curso. A partir de este ejemplo se explican las colecciones más utilizadas, el manejo básico de excepciones y la forma de combinar ambos conceptos en soluciones orientadas a objetos.

## Conceptos clave trabajados en la guía

La solución utiliza distintas colecciones según la necesidad: una lista para mantener estudiantes en orden, un conjunto para evitar duplicados y un mapa para asociar un nombre con un correo. Además, se incorpora manejo de excepciones para evitar que el programa falle al acceder a posiciones inexistentes.


| Colección | Una colección es una estructura que permite almacenar y manipular varios elementos. En Java existen diferentes tipos según la necesidad del problema. |
| --- | --- |
| ArrayList | ArrayList permite guardar elementos en orden y acceder a ellos mediante índices. Es útil cuando interesa mantener secuencia y permitir repeticiones. |
| HashSet | HashSet almacena elementos sin orden fijo y evita duplicados. Es apropiado cuando interesa garantizar unicidad. |
| HashMap | HashMap almacena pares clave-valor. Es útil cuando se necesita asociar un dato con otro, por ejemplo un nombre con un correo. |
| Excepción | Una excepción es un evento que interrumpe el flujo normal del programa debido a un error o situación inesperada. |
| try-catch-finally | try contiene el código riesgoso, catch captura la excepción y finally ejecuta acciones finales independientemente del resultado. |
| throw | throw permite lanzar una excepción de forma manual cuando una condición no cumple las reglas del sistema. |

## ¿Cómo se observan las colecciones en este ejemplo?

Las colecciones aparecen como herramientas para resolver necesidades distintas dentro del mismo sistema. ArrayList se utiliza para mantener una lista ordenada de estudiantes, HashSet para controlar que ciertos datos no se repitan y HashMap para asociar una clave con un valor relacionado. Esto demuestra que no todas las estructuras sirven para lo mismo y que la elección depende del problema.

## ¿Cómo se observa el manejo de excepciones en este ejemplo?

El manejo de excepciones se observa cuando el programa intenta acceder a un índice que podría no existir dentro de la lista. En lugar de permitir que el sistema se detenga, se utiliza un bloque try-catch para capturar el error y responder de forma controlada. Esto mejora la seguridad y la claridad del programa frente a situaciones inesperadas.
